Files in `_drafts/` are never published. Copy this file to
`_posts/YYYY-MM-DD-your-title.md` (for example `_posts/2026-12-01-my-project.md`),
change the front matter above, write in plain Markdown, commit and push.

## A subheading

Normal **Markdown** works: lists, [links](https://example.com), tables, `inline code` and

```python
print("code blocks")
```

Images: put them in `assets/img/` and write `![Alt text](/assets/img/picture.png)`.
